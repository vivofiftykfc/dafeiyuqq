# Changelog

## 0.1.0 — 2026-10-23

- First public source snapshot integrating QQ bridge, Douyin SDK, conversation memory and local companion tools.
- Added optional voice service source and advanced WeChat integration source.
- Added configuration templates, dependency guide, architecture, migration and troubleshooting documentation.
- Added an original repository banner, contribution/security guidance and offline CI.
- Excluded private configuration, identity, conversations, diaries, credentials, model weights and installed runtimes.

Native WeChat clean-machine installation and complete multi-platform cold-start acceptance remain outside this initial public release.
