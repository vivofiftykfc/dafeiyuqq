# 验证记录

首个源码版本的本机验证：

- Windows本机安装 `qq-bridge` 锁定依赖成功；保留上游 `.npmrc` 的 `legacy-peer-deps=true`。
- JavaScript模块语法和JSON检查通过。
- Python集成源码通过AST解析；这不等于已安装全部可选Python依赖。
- 5组隔离离线测试通过：三平台记忆与归档、对话连续性与身份隔离、长期记忆注入、媒体输入处理、QQ DNS边界。
- 新配置启动检查使用虚构账号、隔离DSH_HOME和独立端口，避免连接维护者的生产账号。
- 本机目录迁移后，普通微信后台、原生绑定与控制台分别检查；没有为了验收向真实联系人发送消息。

目标机器仍需完成QQ真实收发、模型账号可用性、CUDA生成、手机授权及可选微信后端的独立验收。此仓库不宣称全新Windows系统上的完整冷启动已验证。
